# RBAC1 权限中心前端

Vue 3、TypeScript、Vite、Element Plus、Vue Router 和 Pinia。对接仓库中的 `rbac1-structured` 后端，沿用 [RBAC1 原型](../docs/02-ui-design/RBAC1界面原型.html)的布局与配色。

## 本地启动

要求 Node.js 22.19 或兼容版本、npm。以下命令在仓库根目录执行：

```powershell
cd frontend
npm ci
npm run dev
```

默认访问 `http://127.0.0.1:5173`。Vite 把 `/auth`、`/api/v1` 原路径代理到 `http://127.0.0.1:8081`。端口占用时会明确报错。

需要修改后端地址时，将 `.env.example` 复制为 `.env.local`，设置 `RBAC_API_TARGET` 后重启 Vite。该变量只用于开发代理。

真实数据操作前，按 [RBAC1 后端说明](../rbac1-structured/README.md)准备 MySQL、JWT 密钥、管理员密码并启动后端。使用后端实际创建的统一账号登录；前端没有演示账号、默认密码或内存业务数据。

Windows 若执行策略阻止 `npm.ps1`，可使用 `npm.cmd` 运行相同命令。

## 功能

- 统一登录、刷新后恢复身份、退出当前会话；令牌仅保存在当前标签页的 `sessionStorage` 中。
- 应用、菜单按钮权限与 API 登记维护；权限绑定完整 API ID 列表，解除关联保留登记。
- 角色搜索、类型筛选、权限配置和删除；支持多父角色继承、有效权限与实际来源展示。
- 用户部门维护、账号停用、总管理员调动用户及任免部门管理员。
- 单人最终角色列表替换、跨页选择用户后批量分配或撤销角色。
- 我的权限、权限申请与撤回、候选角色审核、角色创建申请与受理。
- 操作记录搜索与分页；导航窄屏折叠，表格在容器内横向滚动。

只读继承权限不写入直接权限列表。切换父角色时，新勾选但已被父角色提供的直接权限会转为继承来源，已保存的重叠直接权限保留。按钮的菜单依赖按最终有效权限判断，后端保存校验是最终依据。

页面按管理员职责和当前权限控制访问。无权限导航仍保留，点击显示提示与申请入口，不加载受保护页面数据。按钮缺少权限时打开申请入口。授权申请不会改变管理员身份或管理范围。

## 代码入口

```text
src/
  api/          请求、完整分页读取、RBAC1 接口与数据类型
  components/   角色编辑器、权限来源表、权限按钮、申请弹窗
  composables/  页面请求状态、错误反馈和确认框
  domain/       继承预览、来源去重、角色候选与菜单依赖
  layouts/      导航与当前身份
  router/       路由、菜单与职责规则
  stores/       会话和申请入口状态
  views/        各业务页面
  styles.css    全局配色、排版和响应式布局
e2e/            浏览器业务流程测试
```

`api/types.ts` 对照 RBAC1 DTO；成功响应直接返回业务数据，错误按 `application/problem+json` 显示服务端提示。401 清理失效身份并回到登录页，403 保留会话；204 不解析 JSON。网络失败时保留表单供重试。

## 检查与构建

```powershell
npm test
npm run test:e2e
npm run build
```

单元测试覆盖真实的请求封装、会话和继承计算。浏览器测试使用本机 Chrome，测试启动独立 Vite 服务，并在 HTTP 边界提供契约示例响应；覆盖真实前端交互和提交内容，不会操作本地数据库。若没有 Chrome，可在 `playwright.config.ts` 调整为已安装的浏览器。

浏览器测试不替代真实 MySQL 后端联调。测试截图、trace 和构建产物均已忽略。

生产构建输出在 `dist/`。部署时需由宿主服务器为前端路由提供 `index.html` 回退，并将 `/auth`、`/api/v1` 反向代理到真实后端；`vite preview` 仅供检查构建输出。本次未配置生产部署。
