# 正式前端接入设计

2026-10-22，D-104。用户授权在根目录 frontend 实现原型对应的真实前端，接入既有 API；后端、迁移、契约均不修改。基线包含本地 BE-33 已验证实现，尚未交付 main。本轮不推送、合并或部署。

## 界面与模块

沿用原型 Material 3 浅色工作台：画布 #F8FAFD、白色表面、正文 #1F1F1F、主色 #0B57D0、选中 #D3E3FD、错误 #B3261E。使用原型本地 Roboto / Noto Sans SC 字体、Material 图标和许可证。左侧导航、上方身份及管理范围、左对齐业务表格、按需详情和表单；桌面 256px 侧栏，小屏抽屉。首页为员工授权，无虚构统计。

页面：登录/强制改密；员工授权及任职/来源；角色元数据及权限配置草稿；申请固定内容/预览/提交/状态/时间线/投递重试；审计；系统及目录；后台账号及管理范围；组织浏览、文件上传/字段映射/预检/整批提交及报告。

src/api 从 Git OpenAPI 派生类型和路由；统一请求负责凭据、单项任命上下文、错误和幂等。页面负责用户选择、服务端分页和显式确认；公共组件负责表格、选择器、预览和弹窗。真实页面不引用 prototype/data.ts 或 store.ts，不包含演示账号及内存模拟数据。

## 一致性与安全

- 管理员 token 只在内存，刷新重新登录；登录不带 Authorization，无刷新令牌。改密成功后清除会话。401 返回登录，409 提示重新读取，不能自动覆盖。
- 权限管理员每次按单项任命传三个上下文头；切换清除旧页面和选择。响应过期后不得覆盖新上下文。平台入口仅总管理员可见，服务端仍最终鉴权。
- 写入使用客户端生成 UUID 幂等键；同一内容的未知结果重试保留原键，不自动重发。修改内容、刷新预览才建立新操作。
- 预览展示服务端影响、警告及受限可见性；提交使用原预览和原版本，不修改已预览内容。一般配置/授权/撤销走申请，来源关闭、全局状态、范围和导入使用各自直接入口。
- 不持有 BusinessJwt/OaJwt，不调用 integration/oa 接口。原型“权限调用演示”不进入正式产品；OA 审批在外部完成，前端只查询状态及重试投递。
- 开发服务器 /api 同源代理到本机后端，生产由反向代理承接；不为跨域改后端。

## 验证计划

按项目 TDD：先验证传输边界、会话/上下文、原子预览流程的失败测试，再实现。使用受控 HTTP 服务或浏览器 API 拦截验证前端请求及显示结果，明确不等同真实后端联调。运行类型检查、生产构建和浏览器测试，检查桌面/移动布局。真实后端可用性只读核对；没有可用演示账号时不修改既有数据库，不声称真实全链路已完成。发现后端问题先报告。
