## 页签与阅读顺序

| 正式用例 | 流程重点 |
| --- | --- |
| UC-01 | 总管理员维护系统与目录，支持范围／菜单可见条件校验，直接保存，不经 OA |
| UC-02 | 角色草稿／配置、合法范围、差异预览、固定方案、外部审批及 UC-11 衔接 |
| UC-03 | 员工—角色配对、持续任职条件、排除重复、审批后新增授权 |
| UC-04 | 指定关联撤销、无变化历史、OA 执行、剩余来源保留 |
| UC-05 | 当前公司／系统全量权限、进入资格、菜单、操作及范围合并 |
| UC-06 | 单项进入／操作权限检查，与实际业务记录判断分开 |
| UC-07 | 总管理员任命专员、共同管理范围、人数／资格、直接生效 |
| UC-08 | 范围内审计查询、分页、安全详情与关联历史，只读 |
| UC-09 | 登录、受限密码状态、持续后台资格、退出；另有账号创建、改密、重置三页 |
| UC-10 | 资料预检／导入、稳定身份、兼岗、失效处理及恢复不自动授权 |
| UC-11 | 可信最终结果、冲突／重复识别、批准独立落地、复核执行、失败自动重试 |

先看 UC-01～04 与 UC-11 理解权限如何登记和生效，再看 UC-05／06 理解如何查询。UC-07～10 解释管理员、审计、登录及人员资料配套规则。各用例是独立目标，排列顺序不是系统启动顺序。

## 关键一致性规则

- UC-02～04 经 OA，审批内部细节不展开，最终结果与实际执行由 UC-11 统一处理。申请提交、批准、执行成功是不同状态。
- 原申请人离任不单独阻止合法固定申请执行；原资格来源与当前目标条件仍需复核。
- UC-05／06 只合并当前公司、当前系统的有效角色；进入资格也必须属于该公司和系统。公司数据隔离、SELF 记录判断由业务系统执行。
- UC-10 员工全局停用使全部业务授权及专员任命失效；任职变化只使不再满足条件的授权／任命失效。恢复身份或任职不恢复旧授权，重新申请或任命。
- 服务故障与正常拒绝分开；不能故障默认允许，也不能将服务故障伪装成成功空权限。通用服务故障有些以侧边备注表达，发生时立即终止本次主流程。
- 后台管理员资格与外部业务进入权限独立；任命或后台登录不授予业务权限。
