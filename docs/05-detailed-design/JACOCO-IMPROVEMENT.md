# JaCoCo 测试与采集验证

## 采集验证

测试专用 JavaSubprocess 工厂转交当前测试 JVM 的 JaCoCo agent，为独立 Java 子进程分配独立 exec 文件；保留各命令既有环境清理，不转交 Mockito。正式运行采集 56 个非空子进程文件并汇总，未出现类与执行数据不匹配警告。

## 结果断言

- 初始化与启动：真实打包Web健康响应、迁移进程退出及3项迁移历史；数据库不匹配、初始化SQL故障连接关闭、无隐式建管理员和输出脱敏。
- 身份与错误响应：凭据DTO日志脱敏、事务外身份读取拒绝、损坏读取guard不暴露会话、容器错误分派状态边界、认证401与授权403分别映射。
- 幂等：非法主体不保留请求、持久响应中的敏感字段拒绝回放、缺失加密提供者时拒绝HMAC/JWT、错误响应重放保持业务结果而使用当次请求编号。
- 事务与导入：写guard被意外修改时整笔回滚、审计校验失败被调用者捕获仍禁止提交、内部写端口拒绝服务身份、真实重复键冲突返回过期预览；显式组织映射与未知导入类型校验。
- 申请执行：可编辑草稿不能作为固定申请加载；角色配置生效后旧待审批授权整份失效并释放占用，不创建授权。
- 来源与目录：来源周期耗尽拒绝关闭且保留有效授权，重复请求安全回放；停用导航将子功能权限纳入影响；范围外角色/任命影响不得泄露隐藏标识。
- 现有输入、文件、审批、恢复与并发测试包含于完整回归，正式业务源码、API与迁移未因本轮补测改变。

临时将授权失败映射成401、将Login.toString改为输出密码时，分别由对应新增断言识别，均为断言失败而非运行错误；临时变异已还原。新增场景针对现有行为补充断言；测试夹具/预期修正不作为生产缺陷或TDD修复证据。

## 额外异常路径验证

- 文件发布使用固定随机标识制造真实硬链接冲突：原文件不被覆盖，暂存文件仍可重试。临时将原子链接替换为覆盖复制时，新增断言真实失败；变异已还原。
- 来源持久化端口注入两种版本冲突与未知拒绝，验证冲突安全回放及其他异常原样传播；未用mock替代上层鉴权、事务或持久化幂等记录。
- 真实缓存记录要求全局权限时，范围管理员得到403，缓存内容不泄露，角色及审计不改变。角色配置拒绝的业务码通过真实错误场景逐项断言。
- 未知导入动作在冻结前构造后封存，封存后修改仍被数据库触发器拒绝；提交遇到未知动作时整批回滚。文件访问拒绝不能被改记成存储故障或失败批次。
- 专属子JVM仅在Flyway公开依赖边界注入pending/current状态，实际数据库validate仍执行。通过迁移库接收到的真实DataSource验证凭据覆盖拒绝，无私有反射；演示命令随后使用显式配置成功。该类子JVM单独启用Mockito agent，其余应用子进程不转交Mockito。
- PeopleQueries的未知资源调用被拒绝，正常HTTP读取仍成功。

这些场景验证的是异常处理契约；故障注入和受损持久化夹具均在测试代码及隔离资源中，不修改正式实现或关闭不可变约束。
