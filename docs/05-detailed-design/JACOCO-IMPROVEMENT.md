# JaCoCo 测试与采集验证

## 采集验证

测试专用 JavaSubprocess 工厂转交当前测试 JVM 的 JaCoCo agent，为独立 Java 子进程分配独立 exec 文件；保留各命令既有环境清理，不转交 Mockito。真实子 JVM 的采集回归先复现失败（应有执行文件、实际没有），接入后通过。正式运行采集48个非空子进程文件并汇总，未出现类与执行数据不匹配警告。

## 结果断言

- 初始化命令：检查非法登录名、系统库、空配置、URL凭据/片段/端口边界，断言退出码、无账号/审计写入与输出脱敏。
- 演示命令：检查非法配置不写服务/审计、BUSINESS服务绑定系统、真实JWT验证、停用后不签发和不落盘。
- 输入/文件：检查Unicode长度、版本安全整数、分页溢出、完整UUID、布尔值、搜索转义、上传大小和类型、损坏XLSX、关系/单元格结构与文件发布完整性。
- 幂等：检查响应状态与Location、敏感字段别名、错误JSON、元数据、防御性复制、密钥配置和独立HMAC向量。

空字符串或空白串解析为 MissingNode 时必须拒绝保存为幂等 JSON 正文。该行为先由真实失败断言复现，再最小增加 isMissingNode 拒绝；合法 JSON 字面量 null 与204空正文均保持允许。

临时移除分页溢出保护、正文返回值防御性复制时，各有1项新增断言失败且无运行错误，证明这些断言能识别实际错误；临时变异均已还原。
