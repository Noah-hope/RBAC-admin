# 前端后置交接

现有界面原型已完成当前阶段交付，见[原型入口](../02-ui-design/README.md)及[阶段评审](../02-ui-design/STAGE-REVIEW.md)。本轮后端详细设计不重做UI、不创建正式前端工程或联调实现；D-029的原型补齐优先级保持，相关后端API语义必须实现。

本期用Apifox调用真实后端及演示OA展示功能；原型仍明确Mock，不能用原型按钮/内存审批替代后台实际执行结果。未来正式前端沿用页面与交互基线，按以下接口责任接入：

| 页面/操作领域 | 后续前端职责 | 后端本期验收责任 |
| --- | --- | --- |
| 登录/本人改密/任命切换 | 内存保存短期token、受限token只改密/退出；选择单项当前任命及三上下文头；401清会话、409 CONTEXT_CHANGED重读 | 当前账号/员工/任命/范围和会话持久有效校验，不能信前端身份 |
| 系统目录/角色 | 稳定树排序、独立操作勾选、元数据/配置版本分开，当前有效配置与待审批状态分别显示 | 最终树/同系统/无环、配置差集/空配置及共享角色边界 |
| 员工角色/来源关闭 | 明确员工-role-source明细，完整employmentIds及0基线，不隐式笛卡尔积；确认前重新预览 | 同源去重、异源并存、原子批量、周期和关系版本、迟到批准不复活 |
| 申请/OA状态 | 展示投递/批准/执行三轴，202不展示为已授权；只在契约允许条件显示投递重试 | 固定申请、可靠关联/最终结果、后台执行恢复，无公开管理员批准/强制执行入口 |
| 影响与审计 | 同previewId分页，陈旧重预览；SCOPED/hasUndisclosedImpact按不完整解释；只展示返回的安全目标 | 统计/ID/详情统一当前范围，隐藏混合申请和数量不泄露 |
| 导入/人员状态 | 文件→映射→冻结预检→确认，显示规范化前后值/问题；保持同key重试和版本 | 正式文件边界、Q-01动作顺序、1000行原子提交、恢复不复权 |

正式API客户端未来从Git1.2.0生成/维护，Apifox指定导出仅作协作，普通默认导出和MCP已知差异不成为第二契约。前端错误展示保留Problem的安全码/fieldErrors，不自行重写版本/裁剪目标。前端任务及人时不在本期35个后端Issue预算内，后续另排。
