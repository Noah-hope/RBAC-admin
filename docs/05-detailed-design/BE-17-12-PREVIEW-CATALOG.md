## 原设计与实施顺序

遵循 AGENTS.md、UC-01、API 1.2.0、数据库 T0/T1/T11、BE-08 单项上下文与既有幂等/审计。不改需求、契约或迁移。先实现 BE-17 的受控预览存储、同快照安全影响计算、分页及确认依赖端口，再实现 BE-12 六个契约操作作为实际消费者。

BE-17：在 guard 写上下文内创建五分钟快照，绑定创建账号、单项任命与双版本、操作/资源、规范输入摘要、明确依赖和集合断言。分页使用固定安全投影，不重新混算；每次读重新鉴权，过期/上下文变化拒绝整个快照。确认由外层写命令在同一 guard 下重算依赖，检测原本为空集合中的新增对象，不使用全库 guard.revision。全量权限计算与可见影响分开；员工按员工/公司/系统、来源按四元键去重，混合申请只有整份目标可见才披露。内部端口可供 A/C/D 使用，不提前实现其命令或 OA 流程。

BE-12：总管理员创建系统资料/启停预览和目录预览；确认需当前资格、预期版本、相同输入与预览依赖；同幂等事务完成整个批次、审计和安全结果。目录读取接受当前单项管理范围，过滤后计数分页，返回 X-Catalog-Version。四类命令为 NODE_CREATE/NODE_UPDATE/PERMISSION_CREATE/PERMISSION_UPDATE，最多 100 项，无删除。完整同系统最终图校验本地引用、唯一性、类型、菜单绑定、无环及对象版本；先分配创建 ID，再按最终父依赖插入停用节点、操作、绑定与最终状态，处理即时外键。无变化不推进业务版本、不写变更审计；实质改变只推进受影响对象及一次 catalogVersion。目录停用保留绑定和角色/grant，操作恢复只恢复仍有效关系。

## 实际实现与接入

BE-17 的 `query/preview` 提供 `ImpactPolicy` 纯计算、`ImpactService.analyze` 同事务事实/依赖分析、`PreviewService.create/confirm/bindings` 受 guard 控制的固定快照及确认；`PreviewController` 实现两个分页 GET。BE-12 的 CatalogInput/Planner/Repository/Service 与 Controller 实现六个契约操作，无新增依赖、迁移或环境变量。

| 操作 | 路径（均以 /api/v1/admin 开头） |
| --- | --- |
| 系统资料/启停预览 | POST /systems/{systemId}/state-previews |
| 系统资料/启停保存 | PUT /systems/{systemId} |
| 目录节点读取 | GET /systems/{systemId}/directory-nodes |
| 操作权限读取 | GET /systems/{systemId}/permissions |
| 目录批次预览 | POST /systems/{systemId}/catalog-previews |
| 目录批次保存 | POST /systems/{systemId}/catalog-changes |
| 固定员工影响明细 | GET /previews/{previewId}/employees |
| 固定目标影响明细 | GET /previews/{previewId}/targets |

沿用现有身份启用配置：先使用真实登录令牌；系统/目录写仅总管理员。范围管理员读取携带 BE-08 既定单项任命及双版本头，不合并任命。先 GET 系统/目录取得当前版本，再按 OpenAPI 原模型提交预览与保存；保存使用同一个 input、previewId 及 UUID Idempotency-Key。节点/权限读取按稳定顺序过滤、分页，返回 X-Catalog-Version；目前在同快照加载该系统目录后内存过滤/切页，不宣称数据库侧大规模分页优化。

内部消费者需在自身 CommandBoundary guard 下解析当前资格，用完整相关 systemIds 和类型化 Change 调用 analyze，再将其 dependencies/projection 传给 create；确认时用同输入和同场景重新 analyze 并 confirm 后才执行本模块写入。调用方仍须合并自身命令特有的资格/版本/分类依赖，不可把通用分析当作 A/C/D 命令已实现。create 要求 WriteContext 数据源和账号匹配；analyze 要求调用方已拥有同数据源事务。系统目录与权限额外目标保存在结果快照，其他安全目标和员工保存在 preview_item，未扩张既有枚举或迁移。依赖仅保存排序事实集合的摘要，不持久化隐藏原始行；可见快照仅创建者可读，含当前上下文重新检查。规范输入对象键排序，数组顺序保留，不冒充 OA 的 RFC8785 实现。

新来源无需先物化 authorization_source 即可计算当前任职与预计进入资格。全量来源并集包括不可见部门，但披露仅当前范围；混合范围待执行申请不披露半份。功能预览复核新授权/任职/申请及空集合断言，无关角色改名不失效；纯元数据变更不因无关新授权机械失效。目录最终图校验支持前向本地引用，名称交换用事务内临时唯一名过渡；停用绑定的查看权限不删除绑定/角色/grant。NO_CHANGE 在上限版本仍合法，但必须通过当前版本、资格和预览检查。

共享核心唯一调整：IdempotencyCoordinator 的安全失败白名单加入 PREVIEW_STALE，保持既有状态机、授权回调及幂等事务；否则合法陈旧预览会被基础设施错误转换为 500。完整旧模块回归已运行。
