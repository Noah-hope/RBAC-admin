# BE-27：员工状态及管理范围替换的跨域失效

员工停用现在会在同一事务中持久失效全部来源授权、管理员任命和后台会话，并使受影响的整份固定申请失效；恢复员工仅恢复身份，旧权限与会话保持失效。

管理范围支持完整替换公司、部门、系统集合及管理员名单。未变任命保留ID，移除后重新任命生成新ID；范围缩小导致旧申请失效后，扩大范围也不会复活。仍有其他有效任命时保留会话，失去最后有效资格时撤销旧会话。

- 实现既有四个状态/范围预览与保存接口，复用固定预览、当前总管理员资格、guard、幂等和审计。

- 沿用现有契约、数据库迁移及配置，无新增环境变量。
