## UC-07 配置管理员及管理范围

详细依据：[原用例](UC-07_配置管理员及管理范围.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 后台管理资格 |
| 参与者 | 权限中心总管理员 |
| 描述 | 为各公司配置权限管理专员及共同管理的系统范围。 |
| 触发事件 | 公司需要任命、替换专员，或调整可管理系统。 |
| 前置条件 | 总管理员已登录；公司和候选人员资料已登记。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 总管理员选择公司。 | 总公司或分公司标识 |
| 2. 系统展示当前专员及共同管理范围。 | 专员名单、公司部门范围、系统集合 |
| 3. 总管理员调整可管理系统及专员名单。 | 最终专员名单、获准系统 |
| 4. 系统展示变更和对后续管理的影响。 | 任免差异、系统增减、待处理申请影响 |
| 5. 总管理员填写原因并确认。 | 变更原因、确认内容 |
| 6. 系统保存配置并显示生效结果。 | 最新名单及管理范围 |

| 扩展场景 | 信息 |
| --- | --- |
| 3a. 候选人没有账号：先按 UC-09 配套流程创建，再继续任命。 | 员工标识、后台账号 |
| 3b. 候选人不符合任职条件、重复或超过3人：提示修正，不能保存。 | 问题人员、人数 |
| 5a. 明确提交空名单或空系统集合：提示暂时无人／无系统可管理，确认后保存。 | 影响提示、原因 |
| 5b. 资格无效或配置已变更：拒绝，重新读取后办理。 | 拒绝原因 |
| 6a. 保存失败：保留原名单及范围。 | 失败说明 |

其他：不经过 OA。每公司通常1～3人，同公司专员共享范围内角色；不按创建者分配管理权。公司边界不跨其他公司节点。任免或缩小范围不自动删除业务授权，不自动授予系统进入权限。员工停用使任命失效，恢复后总管理员重新任命。
