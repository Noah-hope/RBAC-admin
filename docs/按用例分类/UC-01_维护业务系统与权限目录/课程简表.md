## UC-01 维护业务系统与权限目录

详细依据：[原用例](UC-01_维护业务系统与权限目录.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 系统与权限目录 |
| 参与者 | 权限中心总管理员 |
| 描述 | 维护接入系统、菜单及功能操作，供角色配置和业务权限查询使用。 |
| 触发事件 | 新系统接入，或已有系统需要增加、修改、停用权限目录。 |
| 前置条件 | 总管理员已登录；待维护内容的业务含义及归属明确。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 管理员选择已有系统或登记新系统。 | 系统名称、编码、说明 |
| 2. 系统展示该系统的权限目录及系统进入权限。 | 系统进入权限、目录树、当前状态 |
| 3. 管理员维护菜单、操作权限及菜单可见条件。 | 菜单层级、操作编码、功能归属、关联查看／进入页面权限 |
| 4. 系统展示变更及对已有授权的影响。 | 新增、修改、启停明细及影响提示 |
| 5. 管理员核对变更，填写原因并确认保存。 | 确认内容、修改原因 |
| 6. 系统保存目录并显示维护结果。 | 保存结果、最新目录 |

| 扩展场景 | 信息 |
| --- | --- |
| 3a. 编码重复、归属错误或菜单绑定不合法：提示原因，返回第3步修正。 | 问题字段、规则说明 |
| 3b. 停用或恢复目录：第4步提示对子目录及已有授权的影响，确认后保存；保留历史。 | 受影响目录及授权 |
| 3c. 删除已引用项或跨系统迁移：拒绝，改用新增与停用方式。 | 拒绝原因 |
| 5a. 内容已被他人修改：重新读取并核对后提交。 | 最新内容、冲突提示 |
| 6a. 保存失败：本次变更不生效，提示稍后重试。 | 失败说明 |

其他：无需 OA 审批。每系统有独立进入权限，登记不等于授予；新增目录不自动授权。清单中含义不明的项目须核对，不猜测“全部”。
