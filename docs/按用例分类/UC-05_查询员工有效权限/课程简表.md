## UC-05 查询员工有效权限

详细依据：[原用例](UC-05_查询员工有效权限.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 对外权限服务 |
| 参与者 | 业务系统后端 |
| 描述 | 查询员工在当前公司、调用方所属系统的进入资格、可见菜单及允许的功能操作。 |
| 触发事件 | 业务系统需要取得员工当前权限，例如展示功能入口时。 |
| 前置条件 | 调用方已登记；业务系统自行认证员工，并可信传递统一员工标识。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 业务系统提交员工与当前公司权限查询请求。 | 服务身份、员工统一标识、当前公司、系统标识 |
| 2. 权限中心确认调用身份、公司和系统，检查员工有效性及任职。 | 身份和系统匹配结果、公司及员工任职 |
| 3. 权限中心确定员工在当前公司、当前系统的进入资格及有效权限。 | 进入资格、未失效的已生效授权 |
| 4. 权限中心返回进入资格、可见菜单及允许的功能操作集合。 | 进入资格、菜单集合、功能操作集合 |
| 5. 业务系统接收结果，用于本系统入口和功能展示。 | 权限结果、菜单与本地页面的对应关系 |

| 扩展场景 | 信息 |
| --- | --- |
| 2a. 参数不合法、身份无效、跨系统或系统停用：拒绝查询，返回错误。 | 错误原因 |
| 3a. 员工不存在、停用、无当前公司有效任职或无该公司进入资格：返回无进入资格，菜单和操作为空。 | 进入资格为否、空集合 |
| 3b. 有进入资格但无功能授权：返回有进入资格，菜单和操作为空。 | 进入资格为是、空集合 |
| 4a. 查询服务故障或授权数据异常：返回错误，不伪装为空权限。 | 服务错误 |

其他：同公司、同系统有效角色权限取并集；相同功能操作去重，不同操作互不推导。菜单须有对应查看／进入页面权限，祖先可仅作导航。编辑权限不自动推导查看权限。业务系统负责后续功能访问拦截；待审批方案不参与计算。
