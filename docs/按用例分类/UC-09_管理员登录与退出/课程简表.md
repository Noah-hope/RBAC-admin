## UC-09 管理员登录与退出

详细依据：[原用例](UC-09_管理员登录与退出.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 后台访问 |
| 参与者 | 权限中心总管理员、公司权限管理专员 |
| 描述 | 管理员登录和退出权限中心后台；配套支持账号建立及密码维护。 |
| 触发事件 | 管理员访问登录页面，或已登录管理员选择退出。 |
| 前置条件 | 登录前后台账号已建立，账号、关联员工（若有）及管理资格有效。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 管理员输入账号和密码并提交登录。 | 本平台登录名、密码 |
| 2. 系统验证账号及当前管理资格。 | 账号／员工状态、管理资格 |
| 3. 系统显示登录成功及当前管理范围。 | 管理员身份、公司和系统范围 |
| 4. 管理员进入获准的管理功能。 | 可用管理功能 |
| 5. 管理员结束使用并选择退出。 | 当前登录状态 |
| 6. 系统结束本次登录，返回登录页面。 | 退出结果 |

| 扩展场景 | 信息 |
| --- | --- |
| 2a. 账号、密码或管理资格无效：统一提示登录失败，不进入后台。 | 失败提示 |
| 3a. 首次／重置后使用临时密码：只允许改密或退出；改密成功后重新登录。 | 原密码、新密码、确认值 |
| 4a. 管理资格取消或范围缩小：后续操作按最新资格处理。 | 当前有效范围 |
| 4b. 本人改密：验证并保存新密码，使全部旧登录失效，重新登录。 | 原密码、新密码 |
| 6a. 已退出或登录过期：维持已退出状态，不恢复旧登录。 | 退出结果 |

其他：仅本平台账号，不负责外部系统登录；无自由注册，不经 OA。配套：总管理员为有效员工创建唯一账号及临时密码，再由 UC-07 任命；可重置专员密码并使旧登录失效。账号创建／密码重置不自动授予管理或业务权限。员工停用使任命失效；恢复后须重新任命，旧登录不能恢复资格。服务故障不作为密码错误。
