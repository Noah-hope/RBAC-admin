## UC-06 检查员工指定操作权限

详细依据：[原用例](UC-06_检查员工指定操作权限.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 对外权限服务 |
| 参与者 | 业务系统后端 |
| 描述 | 查询员工是否拥有指定系统进入权限或功能操作权限，并返回适用范围。 |
| 触发事件 | 业务系统准备让员工进入系统或执行某项受保护操作。 |
| 前置条件 | 调用方已登记，员工身份由业务系统认证并可信传递。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 业务系统提交员工、当前公司及待检查权限。 | 服务身份、员工统一标识、当前公司、系统、权限编码 |
| 2. 权限中心确认调用身份、公司及系统归属、员工状态和任职。 | 调用资格、公司、员工状态与任职 |
| 3. 权限中心判定指定权限是否有效且已获授；功能操作同时要求系统进入资格。 | 权限类型、有效授权、进入资格 |
| 4. 权限中心返回有无该权限及其范围。 | 有无权限；功能为 SELF／ALL，进入权限无范围 |
| 5. 业务系统据结果执行访问限制及自身业务校验。 | 拒绝／继续处理、本人数据限制 |

| 扩展场景 | 信息 |
| --- | --- |
| 2a. 参数错误、身份无效、跨系统或系统停用：返回调用错误，不提供正常鉴权结果。 | 错误说明 |
| 3a. 员工无效、权限未知／停用、未获授或缺少所需进入资格：返回无权限。 | 无权限、范围为空 |
| 3b. 检查系统进入权限：直接判断其授权，不要求功能权限，范围为空。 | 进入权限结果 |
| 4a. 查询故障或数据异常：返回服务错误，业务系统不能据此放行。 | 服务错误 |

其他：可独立调用，不要求先调用 UC-05。权限中心不查询外部业务记录，不判断某条记录归谁；SELF 由业务系统落实。按当前公司、系统计算；业务系统负责公司数据隔离。ALL 仅表示不限本人，不替代其他业务约束。
