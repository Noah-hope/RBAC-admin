## UC-08 查询授权审计记录

详细依据：[原用例](UC-08_查询授权审计记录.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 授权审计 |
| 参与者 | 权限中心总管理员、公司权限管理专员 |
| 描述 | 在管理范围内查询角色配置与员工授权的历史及执行结果。 |
| 触发事件 | 管理员需要核对某次权限变更或追溯授权来源。 |
| 前置条件 | 管理员已登录并具有当前查询范围内的管理资格。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 管理员打开审计查询并填写条件。 | 时间、公司、系统、员工／角色、事件、申请编号 |
| 2. 系统展示范围内匹配记录。 | 摘要列表、结果数量、分页 |
| 3. 管理员选择一条记录查看详情。 | 记录标识 |
| 4. 系统展示变更内容及关联审批、执行情况。 | 操作者、时间、变更前后、审批和执行状态 |
| 5. 管理员核对记录，或调整条件继续查询。 | 查询条件、核对结果 |

| 扩展场景 | 信息 |
| --- | --- |
| 1a. 条件不合法：提示修正，重新查询。 | 问题字段 |
| 2a. 无匹配记录：显示空列表，不作为服务故障。 | 零条匹配结果 |
| 2b／4a. 资格失效或超范围：拒绝访问，不泄露目标内容。 | 不可访问提示 |
| 4b. 员工或角色已改名、员工停用或授权失效：在授权范围内仍展示对应历史。 | 历史身份及名称 |
| 2c／4c. 查询服务故障：提示错误，不显示成没有日志。 | 服务错误 |

其他：只读，不修改、删除或重放历史。批准与执行成功分别展示；历史不等于当前权限。专员查本公司来源且当前获准系统内记录；全局目录和任免日志仅总管理员查看。
