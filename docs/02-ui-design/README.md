# 前端界面原型

**当前交付：** 用户已确认执行 [Material Design 3 改造方案](MATERIAL3-PLAN.md)。0.2.0 原型已实现并验证，待用户评审；当前运行页面已采用浅色 Material 3 风格。

版本：0.2.0；更新日期：2026-10-16。基于 V1.2 需求，使用项目 `frontend-design` skill；保留 7 个管理主页面、独立权限调用演示及登录/帮助。界面使用统一业务称呼“权限中心”，不再展示早期视觉提案名称“衡序”。

浅色侧栏、白色表面、蓝色主操作、胶囊形导航与按钮，通过语义 Token 管理颜色、字阶、圆角及 8px 基础间距；中文/拉丁字体和 Material Symbols 本地加载。侧栏底部可打开“术语说明”，文案依据[团队术语表](../project/GLOSSARY.md)。顶部“原型演示工具”默认收起，可切换身份/状态和打开权限调用演示；仅总管理员显示平台管理导航。业务流程继续使用内存模拟。

技术：Vue 3 + TypeScript + Tailwind CSS，Vite 构建。未增加 UI 框架；旧 `@lucide/vue` 包已移除，Material Symbols 采用本地 SVG。源码与锁文件位于 [prototype](prototype/)，资源来源及许可证见[本地资源说明](prototype/public/assets/README.md)。最新设计依据见 [MATERIAL3-PLAN.md](MATERIAL3-PLAN.md)，早期演进记录见 [DESIGN.md](DESIGN.md)，验证见 [VALIDATION.md](VALIDATION.md)。

## 启动

在 PowerShell 中运行：

```powershell
cd D:\NoahProject\rbac-admin\docs\02-ui-design\prototype
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173/**。默认只监听本机，进入权限管理员演示工作区；无需真实账号。展开顶部“原型演示工具”后可切换总管理员和页面状态。当前验证环境为 Node.js 22.19.0、npm 10.9.3，依赖版本由 `package-lock.json` 固定。

其他命令：

```powershell
npm run check
npm run build
npm run preview
```

预览构建默认地址为 http://127.0.0.1:4173/，需要先构建。请通过 HTTP 服务打开，勿直接双击 `index.html`。启动目录始终在本阶段内部，不新增根目录前后端工程。

## 模拟边界

- 角色配置可保存草稿并继续编辑，满足条件的未提交草稿可删除；配置未保存关闭时可继续编辑或放弃。驳回申请可复制为新草稿、更新原因后重提；配置类重提可修改权限，分配/撤销类改变员工或来源时应回到业务页重新选择。
- 员工批量分配逐人固定实际来源，并在提交前预览配对；相同来源已有效项按无变化处理。列表统一 10/20/50 分页，角色/申请/审计等页可筛选；审计关联申请可按当前范围跳转。
- 系统目录支持显示资料、导航层级、菜单查看绑定及独立操作登记；父导航停用影响子功能计算。未绑定查看/进入的新功能保持停用，不能直接启用可打开菜单。这些是内存场景，未验证真实后端唯一性或事务。
- 组织/岗位资料在“导入组织资料”中使用固定 Mock 样例演示字段映射、更名、重复冲突及已有引用的跨公司迁移阻断；不宣称支持任意组织/岗位文件导入。人员变更 CSV 路径继续保留。
- 所有姓名、组织、账号、授权和事件均为虚构；初始样本含两个公司、三个系统、12 名员工，覆盖跨公司兼岗和同角色多部门来源。
- 状态仅在浏览器内存中模拟。刷新页面或侧栏“重置演示数据”会恢复示例；不使用后端或持久化数据存储。
- 登录仅验证演示账号与非空输入，不构成真实认证。账号建立/改密不保存所填密码，请勿输入真实密码。8 位密码长度只是本原型输入校验示例，正式策略待技术设计。
- 演示检查不是安全防护、并发控制或数据库事务。原型浏览器测试不作为后续正式逻辑的 TDD 证据；正式逻辑仍须先测试并实际观察失败。
- OA 批准/执行按钮只在明确标注的原型模拟工具中，不是正式产品的人工审批或强行执行入口；未实现 OA 内部审批流。
- 人员导入只支持当前公司、128KB 以内的演示 CSV，六个字段，不支持带逗号或引号转义的字段；未处理真实 Excel、全量课程数据、真实 HR 连接或跨公司混合批次。
- 系统目录仍使用代表性样例，不宣称已完成所有原始清单映射；角色草稿、逐人批量明细与申请覆盖主要路径，不穷举所有编辑恢复、多人并发和跨批次事务场景。
- 未设计正式 API/数据库，权限验证中的响应仅为界面演示；本轮不修改 V1.2 权威需求，不刷新需求 PNG/SVG。

## 浏览器验证

工程使用 Playwright；当前环境用已安装的 Edge 验证：

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run test:ui
```

其他环境可安装 Chromium 后运行：

```powershell
npx playwright install chromium
npm run test:ui
```

如果当前 PowerShell 已设置 `PLAYWRIGHT_CHANNEL`，使用 Chromium 前清除该变量。测试直接驱动本地原型，不访问外部 OA/HR。构建、依赖与测试产物由 Git 忽略，团队共享源码、锁文件和验证记录。
