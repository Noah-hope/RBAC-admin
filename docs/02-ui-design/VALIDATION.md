## 已自动化覆盖的行为

自动化用例在 [prototype.spec.ts](prototype/e2e/prototype.spec.ts)。

| 用例 | 页面与行为 | 浏览器证据 |
| --- | --- | --- |
| UC-01 | 系统目录、系统启停、功能操作目录 | 停用系统后权限查询显示调用错误，区别于空权限 |
| UC-02 | 公司共享角色只读、草稿与独立操作配置、差异申请 | 部门管理员不能改共享配置；新增草稿选进入与查看，不自动选编辑，批准执行后才激活 |
| UC-03 | 员工来源与任职、提交固定分配、等待批准执行 | 分配提交前后旧授权不变；模拟批准后仍待执行，执行成功后新增来源可见 |
| UC-04 | 关闭原部门来源、保留其他来源、历史只读 | 林予安工程一组失效，工程二组同共享角色保持有效；关闭来源使旧分配失效，迟到批准不能执行 |
| UC-05/06 | 当前公司及调用系统上下文、进入资格、菜单与操作 | 只编辑不推导查看菜单；跨公司兼岗不合并另一公司的功能授权；系统停用返回调用错误 |
| UC-07 | 总管理员范围配置、多项任命与空系统 | 不同任命可明确选择；当前范围为空系统时分配按钮不可用；部门身份访问总管理员页面被阻止 |
| UC-08 | 只读事件、来源范围与平台事件隔离 | 部门管理员查询不到平台任命事件，总管理员可查看；详情无修改/重放入口 |
| UC-09 | 后台账号创建与任命分开、账号停用、本人改密与演示登录 | 账号建立后未任命；添加任命后可见对应资格；停用账号不改业务来源；本人改密清空输入并返回登录 |
| UC-10 | 全局停用/恢复、CSV 预检与新任职 | 全局恢复不复活旧来源；演示批次预检后应用，新员工无自动角色 |
| UC-11 | 投递、批准、执行分开、故障恢复、失效旧申请 | 重投保留同一编号；批准后显示待执行；执行失败不生效，服务恢复后执行；失效旧方案不能复权 |

另外验证了手机导航、页面错误恢复和 Escape 关闭原生对话框。

## 结果的实际范围

- 这些测试在原型实现后作为浏览器回归编写，不冒充正式逻辑的 TDD。正式服务仍须按后续 API、数据库和详细设计先编写并运行失败测试。
- 演示只检查前端状态与结果，没有验证真实后端认证、OA 身份、请求幂等、并发锁、数据库事务、跨服务重试或真实会话失效。
- 页面状态工具可展示加载、空、错误、无权限、过期；未对所有页面与所有异常组合做穷举，也未执行完整无障碍审计或多浏览器兼容测试。
- CSV、功能目录层级、复杂批量配对与草稿恢复等原型局限见 [README.md](README.md)。业务规则始终服从 V1.2 详细用例，原型简化不是需求删减。
