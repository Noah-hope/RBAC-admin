## 配套入口

- [按用例分类阅读](按用例分类/README.md)：11 个以“用例编号_用例名”命名的文件夹，每个归集详细说明、简表、相关图和预览；与原始按类型目录同步。
- [详细用例说明及用例图](usecases-v1/README.md)：主文档、UC-01～11 详细说明、四页可编辑用例图与预览。
- [课程格式用例说明](usecase-tables-v1/README.md)：精简 Markdown、11 页可编辑 drawio 说明表及预览。
- [全部用例流程图](flows-v1/README.md)：UC-01～11 的独立文件、14 页汇总文件与本地预览。
- [全部用例时序图](sequences-v1/README.md)：需求分析级消息交互、15 页可编辑汇总文件与本地预览。
- [全部用例活动图](activities-v1/README.md)：11 个用例、14 页可编辑 UML 活动图与本地预览。
- [顶层与第一层数据流图](dataflows-v1/README.md)：系统边界、处理分解、逻辑数据存储及平衡分析。

当前文件是需求设计，不代表功能已实现。

## 文档使用规则

用户已要求删除弃用的旧需求与教学示例，`docs/history/` 已删除。后续不再引用这些旧方案，也不自动恢复历史目录；当前需求以上方列出的有效资料为准。

之后默认只使用 `usecases-v1`、`usecase-tables-v1`、`flows-v1`、`sequences-v1`、`activities-v1`、`dataflows-v1`。目录中的生成脚本用于维护配套文件；项目根目录的 `.tool-install-review` 是工具安装检查记录，不是需求来源。

`按用例分类/` 是上述资料的同步阅读副本，不另设需求版本。正式修改在原始按类型目录完成，之后运行 `python docs/sync_usecase_folders.py` 更新用例目录；同步器检测到副本有手工改动时停止，避免覆盖。完整需求总览及共享图仍从原目录维护。
