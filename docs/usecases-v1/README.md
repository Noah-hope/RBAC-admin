## 已确认规则

角色属于一个公司、一个系统，可限定直接任职部门；岗位不自动绑定角色。查询按员工、当前公司、业务系统计算，同公司同系统的功能权限取并集并去重；进入资格也按该公司系统计算。本系统只管理功能权限。

员工失去适用任职条件时相关授权失效；全局停用使其全部业务授权和权限管理员任命失效。历史保留，身份或任职恢复不自动恢复旧授权／任命：业务角色经 OA 重新申请，权限管理员由总管理员重新任命。系统、目录的启停与员工停用不同，重新启用只让尚有效的关联重新参与计算。

操作目录登记独立功能权限，角色只配置是否授予；不设计业务数据权限。后台管理资格与外部业务功能权限独立。

UC-02 配置、UC-03 分配及 UC-04 一般撤销经 OA；离岗关权直接生效。OA 批准后自动执行合法固定申请，原申请人离任不单独阻止执行；不实现 OA 内部流程。UC-10 使用稳定内部 ID、来源映射及明确变更模板，不从文件缺行推断离职。HR 一期通过文件导入；业务系统通过简单独立 HTTP 调用演示效果。

一期使用至少两个公司、两个系统的代表性数据，覆盖多角色、兼岗、公司授权隔离、功能操作独立与去重、进入资格、菜单和操作、审批生效、撤销、失效及重新申请。其余资料后续补齐。
