## 业务边界复核

继续沿用V1.3：指定公司/一个平级部门/系统，不拼接任命；公司级共享角色仅总管理员维护；角色/关系/来源分开；一般变更经OA批准执行；来源关闭直接生效；员工恢复不复权；普通员工不登录。原申请人离任不单独阻断自动执行，原范围实质缩小及目标来源关闭须复核。没有发现需要新增这些业务含义的理由。

本次新增字段/更严格Schema/HTTP状态属于未上线契约修订，不能说完全兼容首版。最终版本及迁移说明见下文，用户尚未逐项确认的技术参数仍列为设计取值。
