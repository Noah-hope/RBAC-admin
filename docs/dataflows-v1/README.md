本图包含一个整体处理过程、五类外部实体和十条有向数据流。顶层不画数据库、内部模块、执行顺序或审批内部步骤。后续第一层分解必须保持边界数据流平衡，新增规则须同步详细用例及对应图。

第一层将整体过程分解为 1.0～7.0；完整图与分区图表示同一组数据流。为避免长线交叉，各分区重复引用外部实体和数据存储；同名实体、同编号存储是同一个逻辑对象，九个存储不代表九张数据库表。上下层已按编号核对流向及参与方，并在分析文档核对内容覆盖。

在 draw.io 中通过“文件 → 从以下位置打开 → 设备”打开 drawio 文件，可以编辑实体、处理过程、箭头和数据流名称。所有箭头采用直线。

`generate_context.py` 可复现 drawio、PNG、SVG，会覆盖同名文件；手工修改后不要直接重跑。预览由同一数据在本地辅助绘制，不是实际 draw.io 客户端导出，未将图内容发送至第三方网站。已检查 XML、节点 ID、边界连线、数据流方向与文字尺寸；尚未在 draw.io 客户端人工验收。

`generate_level1.py` 可复现完整第一层、七个分区及其 PNG／SVG、预览入口和平衡记录，同样会覆盖相应文件。所有连线均为直线；图中文字省略的通用身份、版本及错误规则不代表取消这些校验。
