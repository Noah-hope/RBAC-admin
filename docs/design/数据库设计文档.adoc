== 事务、并发控制与存储安全策略

* **关键写操作悲观锁串行化**：修改/删除角色、审核权限申请、修改用户与批量变更角色关联时，通过 `SELECT ... FOR UPDATE` 按固定顺序锁定目标行，防止并发修改导致循环继承、菜单缺失或重复赋权。
* **唯一约束异常翻译**：`uq_user_username`、`uq_role_name`、`uq_application_code`、`uq_application_name`、`uq_permission_application_code`、`uq_api_operation`、`uq_api_route` 等唯一键在数据库层兜底，持久化边界统一将其翻译为明确的 `409 DUPLICATE` 业务错误。
* **凭据不落明文**：`sys_user.password_hash` 保存 Argon2id 密码摘要；`sys_session.token_hash` 仅保存 JWT 的 SHA-256 二进制摘要（`BINARY(32)`），操作日志严禁记录密码与令牌原文。
