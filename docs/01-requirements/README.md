## 文档使用规则

用户已要求删除弃用的旧需求与教学示例，`docs/history/` 已删除。后续不再引用这些旧方案，也不自动恢复历史目录；当前需求以上方列出的有效资料为准。

当前需求配套资料使用 `usecases-v1`、`usecase-tables-v1`、`flows-v1`、`sequences-v1`、`activities-v1` 及 `dataflows`。目录中的生成脚本用于维护配套文件；项目根目录的 `.tool-install-review` 是工具安装检查记录，不是需求来源。

`按用例分类/` 是上述资料的同步阅读副本，不另设需求版本。正式修改在原始按类型目录完成，之后运行 `python docs/01-requirements/sync_usecase_folders.py` 更新用例目录；同步器检测到副本有手工改动时停止，避免覆盖。完整需求总览及共享图仍从原目录维护。
