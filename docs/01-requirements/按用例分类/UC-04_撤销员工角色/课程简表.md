## UC-04 撤销员工角色

详细依据：[原用例](UC-04_撤销员工角色.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 员工授权 |
| 参与者 | 权限中心总管理员、权限管理员；协作：OA 系统 |
| 描述 | 撤销指定员工与角色的授权关系，保留其他有效来源的权限。 |
| 触发事件 | 员工职责变化或不再需要某项角色授权。 |
| 前置条件 | 管理员已登录并具备目标授权来源的撤权资格。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 管理员查询目标员工可管理的角色授权。 | 员工、公司、系统、授权来源 |
| 2. 系统展示范围内仍有效的可撤销关系，失效历史只读。 | 角色关联、状态、来源组织 |
| 3. 管理员选择撤销关系并填写原因。 | 明确的撤销清单、撤销原因 |
| 4. 系统展示撤销明细和可见范围内的影响。 | 角色及权限摘要、重合权限提示 |
| 5. 管理员确认提交，系统受理并交由 OA 审批。 | 固定撤销清单、申请编号 |
| 6. OA 返回最终批准结果，由 UC-11 执行撤销。 | 最终审批结果、执行结果 |
| 7. 管理员查看结果，后续权限按剩余有效角色计算。 | 撤销状态、剩余授权 |

| 扩展场景 | 信息 |
| --- | --- |
| 3a. 关联已撤销：排除无变化项；全部无变化时不发起审批。 | 当前关系状态 |
| 5a. 超管理范围或目标关系已变化：拒绝提交，重新查询。 | 拒绝原因 |
| 6a. OA 驳回：本次申请不改变授权；可修改后重新申请。 | 驳回结果 |
| 6b. 旧方案已不适用：不撤销后续重新授予的新关系。 | 失效原因 |
| 6c. 执行失败：整批不执行撤销，按 UC-11 处理。 | 失败状态 |

其他：撤销关联不删除角色、不停用员工、不影响其他员工；重合权限仍由剩余角色提供。员工来源已关闭或失效时，关系作为只读历史／无变化项；旧回调不得影响重新授予。一般撤销提交不改变授权；离岗关闭原部门来源立即生效并审计，不经 OA，其他来源保留。
