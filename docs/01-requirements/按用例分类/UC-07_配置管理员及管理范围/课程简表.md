## UC-07 配置管理员及管理范围

详细依据：[原用例](UC-07_配置管理员及管理范围.md)

| 项目 | 内容 |
| --- | --- |
| 级别 | 用户目标 |
| 包 | 后台管理资格 |
| 参与者 | 权限中心总管理员 |
| 描述 | 指定权限管理员的公司、管理部门及系统范围。 |
| 触发事件 | 任命、替换管理员或调整部门/系统范围。 |
| 前置条件 | 总管理员有效；公司、部门、候选员工及后台账号合法。 |

| 主成功场景 | 信息 |
| --- | --- |
| 1. 总管理员选择公司和管理部门。 | 公司、指定部门、不跨公司边界 |
| 2. 系统展示具体范围、任命及版本。 | 部门范围、系统集合、管理员名单 |
| 3. 总管理员调整系统和名单。 | 部门/系统增减、任免明细 |
| 4. 系统预览业务影响。 | 后续管理、待执行申请影响 |
| 5. 总管理员填写原因并确认。 | 固定配置、版本、原因 |
| 6. 系统复核并整体保存范围、任命及审计。 | 直接生效结果 |

| 扩展场景 | 信息 |
| --- | --- |
| 3a. 无账号、账号停用或任职不合法：拒绝新增任命。 | 问题身份 |
| 3b. 重复任命、跨公司部门或陈旧版本：拒绝。 | 规则/冲突 |
| 5a. 明确空名单或空系统：提示影响后保存。 | 暂时无人或无系统 |
| 6a. 写入/审计失败：整体回滚。 | 旧范围保留 |

其他：同范围协作，指定部门不跨公司；取消旧公司人数限制。公司共享角色仅总管理员维护，部门管理员可申请分配。任命不授予业务权限，普通员工不登录。
