# RBAC 权限管理中心

本项目实现了结构化设计的 RBAC0 后端，为多个业务系统统一管理菜单和按钮权限。管理员先把权限授予业务角色，再把角色分配给用户。用户可以拥有多个角色，同一项权限只计算一次。

## 已实现的功能

- 用户可以**登录、查询当前身份和退出**。退出后当前会话立即失效。
- 管理员可以**查看部门树，搜索、新增和修改用户**。总管理员可以维护部门结构、调动员工并任免部门管理员。员工调动时保留原有业务角色，账号停用时撤销已有会话。
- 总管理员可以**登记应用并维护菜单和按钮权限**。按钮归属同一应用的菜单，权限标识采用 `资源:操作` 格式，在应用内唯一。
- 总管理员可以**创建和修改业务角色**，为同一个角色配置多个应用的权限。勾选按钮时同时勾选其所属菜单。
- 管理员可以**单独或批量分配、撤销业务角色**。批量操作先校验全部用户是否在管理范围内，整批保存后生效。
- 用户可以按应用**查询自己的菜单和按钮权限**。业务系统使用绑定到本应用的令牌检查用户能否执行指定操作，授权变更在下一次检查时生效。
- 系统记录角色配置、授权变更、员工调动等已成功的操作，**支持搜索和分页**。总管理员可以查看全部记录，部门管理员只能查看管理范围内的用户记录，批量记录按操作发生时的部门筛选对象。

总管理员负责全局配置。部门管理员负责本部门及下级部门的用户维护和业务角色分配。
